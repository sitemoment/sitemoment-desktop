SiteMoment Desktop · 4 种 UI 风格

同一个界面（概览 + SEO Agent）用 4 种风格各做一版，数据完全相同，方便直接对比。点「打开」看 1440×900 原尺寸，图表悬停可看每天的数值。数据都是虚构的。

1 · 原生清爽 打开 ↗

像 macOS 自带应用：浅色、半透明侧栏、系统字体、蓝色强调色。三栏：站点 / 看板 / Agent。

  • 最稳妥，学习成本最低，Windows 上也不突兀
  • 个性偏弱

2 · 深色控制台 打开 ↗

像 IDE 或运维面板：深色、信息密度高、数字用等宽字体，有标签页、⌘K 命令面板和底部状态栏（同步、采集队列、额度）。

  • 适合每天盯数、管很多站的运营
  • 和现在的 /admx 后台气质一致；新手会觉得有点硬

3 · 纸感报告 打开 ↗

概览写成一份周报：先用一句话讲结论，再给数字和图。宋体标题、米色纸张，Agent 像页边批注。

  • 可信、安静，导出的周报和界面一个样
  • 信息密度最低，多站点快速切换不如前两种

4 · Agent 工作台 打开 ↗

以 Agent 对话为中心：左边是站点图标和会话列表，中间是对话（Agent 生成的表可以固定到概览），右边是本站数据。

  • 最能体现「本地数据 + Agent」的卖点，上手就是问问题
  • 看板退居第二，纯看数的用户要多点一下
