# 站点诊断

目标：回答「这个站的 SEO 现在最大的问题是什么、先做哪一步」，结论要有数据支撑：站内问题看巡检，**搜索上的表现看谷歌的实际结果**。

## 顺序
1. **GSC 数据 + 站点体检**（免费）：先用「GSC 数据」看近 28 天的点击、展示和排名变化（本机数据，最准）；再用「站点体检」看 P0/P1 问题：robots 屏蔽、sitemap 里的 4xx、死链、重复标题、页面自相竞争、能抓但没进 sitemap 的页面。
2. **抓取网页**（免费）：首页 + 1–3 个关键落地页，读 Title / H1 / 正文，判断每页在打什么词。
3. **查谷歌的实际结果**（「谷歌搜索结果」，本机浏览器查，免费；本机查不了时用「谷歌搜索结果（付费）」）：
   - 收录：查 `site:域名`，看谷歌收录了哪些页面、数量大概多少。
   - 排名：对 2–3 个主攻词（页面 Title / H1 打的词），查第一页都是谁、这个站有没有出现、是哪个页面、排第几。
   - 竞争：第一页有没有和这个站体量差不多的小站；全是大站的词先放一放。
   - 有 GSC 数据时先看 GSC（真实点击、曝光、排名），再用搜索结果补第一页的对手。
4. **旧网址检查**（免费）：站点改过版、换过路径时必查。404 且没有 301 的旧网址是「越晚越亏」的问题，排第一。
5. **页面速度**（免费）：首页移动端。只有明显差（LCP > 4s、CLS > 0.25）才写进建议。
6. 需要搜索量、难度时用付费工具（可用时）：搜索量先「关键词库存数据」，主攻词再查「关键词难度」。

## 判断优先级
- P0：正在丢流量或阻止收录（旧网址 404、robots 屏蔽、全站 noindex、sitemap 大量 404、核心页面没被收录）。
- P1：压着排名（两个页面抢同一个词且谷歌在两页之间摇摆、标题重复、关键页面薄内容、没有内链、主攻词不在第一页）。
- P2：整理类（sitemap 漏页、分页、速度一般）。

## 不能下的结论
- 只看页面就说「这个词排不上去」或「两页在抢排名」：要用谷歌的实际结果确认。
- 快照库的排名词少 ≠ 站没有搜索流量：快照只覆盖库里的词。
- 一次抓取看到的 Title 和谷歌搜索结果里显示的不同 → 说明谷歌还没重新抓取，不是矛盾。
- 没查到的数据不要估。写「缺」，放进「下一轮要补的数据」。
