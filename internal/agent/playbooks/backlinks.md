# 外链

## 判断
- DR 很低（< 10）的新站，内容再好也很难排竞争词：外链要提前做。
- 先看主攻词前十里最弱的可竞争站有多少引用域，作为第一阶段目标。

## 渠道（按成本从低到高）
1. 目录和导航站提交（AI 工具站有大量专门的导航站），免费，见效快但权重有限。
2. 产品发布社区：Product Hunt、Hacker News（Show HN）、Reddit 相关版块、Indie Hackers。目的是第一批引用和用户。
3. 竞品已有外链的来源：用外链工具导出竞品引用域，筛出能复制的（目录、评测、列表文章）。
4. 客座文章 / 付费外链：用「外链市场筛选」找候选，「外链评估」判断报价是否合理；避开链接农场。

## 不要
- 大量买低质链接（站群、PBN）。
- 全部用同一个精确匹配锚文本。
