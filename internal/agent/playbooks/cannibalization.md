# 页面自相竞争

两个页面的 Title / H1 都以同一个短语开头，或正文明显在答同一个问题，谷歌通常只挑一个排，另一个被压。

## 先用数据确认
巡检只能说明「两页在打同一个词」，是不是真的在抢，要看谷歌：
1. 用「谷歌搜索结果」查这个短语（本机查不了时用「谷歌搜索结果（付费）」）：第一页有没有这个站？出现的是哪个页面、排第几？
2. 再查 `site:域名 短语`：谷歌把这个站的哪些页面和这个词关联起来。
3. 判断：
   - 只有一个页面出现、排名稳定 → 谷歌已经选好了主页面，优先级降低，按下面的方法收尾即可。
   - 两个页面都出现，或出现的页面不是想要的主页面 → 真在抢，优先处理。
   - 这个站根本不在第一页 → 先解决「排不上去」（内容、内链、外链），自相竞争是次要原因。
4. 有搜索量数据时写上量；量很小（每月几十）的词，自相竞争不值得排在前面。

## 处理
1. 定一个**主页面**：谷歌已经在排的那个优先；其次是最贴合这个词意图、内容最完整、内链最多的那个。
2. 其他页面换角度：Title、H1 里不再出现完整短语，改写成更具体的长尾（功能、人群、场景）。
3. 从其他页面用这个短语做锚文本链接到主页面。
4. 两页内容几乎一样：合并，旧页 301 到主页面。

## 首页的特殊情况
首页通常打品牌词 + 泛概念。主攻词有专门的落地页时，首页标题不要再用同一个完整短语。

## 验收
两页的 Title 和 H1 里不再同时出现这个完整短语；几周后用「谷歌搜索结果」再查这个词，只出现主页面。
