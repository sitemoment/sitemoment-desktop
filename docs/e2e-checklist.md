# 端到端验收清单（M1–M5）

负责人在 M2–M5 都合并、后端已经部署后统一测试。用发布出来的安装包（不是 `wails3 dev`）在一台干净的电脑或新的系统用户上测，结果写回 README 的「当前状态」。需要：已部署的后端、Google OAuth「桌面应用」客户端（release 变量 `GOOGLE_CLIENT_ID` 等）、自己的几个站点。

## 安装和更新（M5）

1. 打开 `https://sitemoment.com/seo/download`：两个下载按钮能下载；登录后显示邮箱、套餐、本月积分；页脚「隐私说明」打开 `/seo/privacy`。
2. macOS：打开 .dmg（窗口里有 SiteMoment 和「应用程序」两个图标、中间一个箭头），拖进「应用程序」，从「应用程序」打开。没签名时按提示到「系统设置 → 隐私与安全性」点「仍要打开」。Dock 和「关于」里是 SiteMoment 的图标，状态栏版本号是发布的版本。
3. Windows：运行 `SiteMoment-windows-amd64-setup.exe`，不需要管理员权限，装到 `%LOCALAPPDATA%\Programs\SiteMoment`，开始菜单和桌面有快捷方式；没有 WebView2 的机器会自动安装。SmartScreen 拦截时点「更多信息 → 仍要运行」。
4. 设置 → 软件更新：「检查更新」→「已是最新版本（v…）」，「上次检查」时间更新。
5. 发一个更高的版本（例如 `v0.5.1`，见 RELEASING.md）→ 旧版本打开 30 秒后（或点「检查更新」）右上角出现「v0.5.1 可以更新」→「下载并安装」显示进度 →「重启并更新」→ 应用自己重启，版本号变成 0.5.1，站点、数据、登录状态都还在。macOS 上如果是从 .dmg 里直接打开的，会提示先拖进「应用程序」。
6. 设置 → 通知：「发送测试通知」→ 应用右下角出现提示；第一次会弹系统的通知授权，允许后系统通知中心出现「SiteMoment 通知测试」。把窗口切到后台，触发一次采集验证码或体检新 P0 → 收到系统通知。macOS 没签名时如果系统通知始终不出现，记在 README 的已知问题里（应用内提示不受影响）。
7. 设置 → 隐私说明：三段说明能展开；「完整隐私政策」在浏览器打开 `/seo/privacy`。

## 账号、站点和数据（M1、M2）

8. 登录 SiteMoment：浏览器打开确认页「以 … 登录 SiteMoment Desktop？」→「继续」→ 回到应用，左下角显示账号；退出重开仍是登录状态。
9. 连接 Google 账号 → 添加 5 个站点 → 绑定 Search Console 资源 → 回填 16 个月 → 概览出数；28 天点击和 Search Console 网页的数字一致；7d / 28d / 90d 切换正常。
10. 绑定 GA4 媒体资源和 Bing（粘贴 Bing Webmaster API key）→ 概览多出「会话」和 Bing「点击」。
11. 关键词工作台：「取数 · Bing」填上搜索量；「取数 · SiteMoment」先报价、确认后填上搜索量和 KD，状态栏额度增加。

## Agent 和采集器（M3）

12. 不登录、只填自己的模型 key：Agent 能回答，只出现免费工具。
13. 登录后选 SiteMoment 托管模型问一句 → 额度增加约「token 数 / 1000」；后端 `desktop_credit_events` 有 `kind = 'llm'` 的流水，日志里没有提示词和回答。
14. 完成标准：选一个 GSC 排名 11–20 的词问「<词> 卡在第二页，下一步怎么做？」→ 用到本地数据、采集器（谷歌搜索结果，注明地区和日期）、SiteMoment 数据（先确认再扣积分）三类工具，按「结论 / 依据 / 建议 / 验收」回答。
15. 回答中途「停止」能停；验证码：连续查谷歌直到出现验证码 → 窗口弹出、顶部提示，处理后继续；放 2 分钟 → 失败并建议付费结果。
16. 自己写的采集器放进数据目录的 `collectors/` →「重新扫描」→ 确认域名后 Agent 多出这个工具。

## 体检、任务、周报（M4）

17. 第二天 08:00 之后打开应用（或「立即体检」）→ 每个站点都有体检记录、健康分；故意把一个正常页面改成 404 → 再体检出现 P0、有通知。
18. 让 Agent 把建议变成任务 → 任务页确认 → 每次同步后自动复查；一个 `url_status` 的任务确认后立即通过并通知。
19. 报告页有周报，能导出 HTML 和 Markdown。

## 网页版下线（后端 `[seo] retired`）

20. 负责人确认桌面版可以替代以后，按 sitemoment 仓库 `deploy/k8s/README.md` 的「网页版 SEO Agent 下线」把 `[seo] retired` 改成 `true`：`/seo/` 变成下载页（顶部说明网页版已下线）；`/admx/` 没有「SEO Agent」标签、「我的站」没有「让 Agent 分析」按钮；以前分享的 `/seo/s/<id>` 仍能打开；`curl https://sitemoment.com/api/v1/seo/status` 返回 `{"retired":true}`。
